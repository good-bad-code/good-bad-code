## 01 / ABOUT

I'm a **beginner developer** who enjoys building things for the web.

Python을 공부하면서 개발을 시작했고,
현재는 **Next.js, Django, HTML, CSS, JavaScript**를 이용해
웹사이트와 Chrome Extension을 만들고 있습니다.

완벽한 코드를 작성하는 것보다
직접 만들고, 실패하고, 이해하고, 개선하는 과정을 좋아합니다.

AI 역시 개발 과정에서 하나의 도구로 활용합니다.

> **AI can write code.
> I want to understand it.**

## 05 / HOW I DEVELOP

```text
        IDEA
          │
          ▼
       BUILD
          │
          ▼
       DEBUG
          │
          ▼
       LEARN
          │
          ▼
      REFACTOR
          │
          ▼
       BETTER
```

**Build → Break → Learn → Fix → Repeat**

처음부터 좋은 코드를 작성하는 것은 어렵다고 생각합니다.

그래서 지금은
**나쁜 코드도 직접 경험하면서 좋은 코드를 배우는 중입니다.**
