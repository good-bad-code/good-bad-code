# 🧠 Development Philosophy

## `good code ≠ code that simply works`

처음 개발을 시작하면 가장 먼저 배우는 것은

> **"일단 동작하게 만들기"**

라고 생각합니다.

저도 그렇게 만들고 있습니다.

하지만 그 다음에는 이런 질문을 해보려고 합니다.

```text
Does it work?
      │
      ▼
Why does it work?
      │
      ▼
Can I understand it later?
      │
      ▼
Can someone else understand it?
      │
      ▼
Can I make it simpler?
      │
      ▼
        Refactor
```

완벽한 코드를 처음부터 작성하려고 하기보다는

**만들고 → 실패하고 → 이해하고 → 고치고 → 다시 만들기**

를 반복하면서 성장하려고 합니다.

# 🤖 AI & Development

AI는 제 개발 과정에서 꽤 중요한 도구입니다.

하지만 AI가 만들어준 코드를 그대로 복사해서 사용하는 것보다는,

```text
             ┌──────────┐
             │   IDEA   │
             └────┬─────┘
                  ↓
             🤖 AI 도움
                  ↓
             ┌──────────┐
             │   CODE   │
             └────┬─────┘
                  ↓
            👀 직접 이해
                  ↓
            🧪 직접 테스트
                  ↓
            🛠️ 직접 수정
                  ↓
             🚀 BUILD
```

**AI를 사용하더라도 최종적으로 코드를 이해하는 것**을 중요하게 생각합니다.

AI에게 좋은 질문을 하는 것도 중요하지만,

> **AI가 틀렸을 때 틀렸다는 것을 알아볼 수 있는 개발자**

가 되는 것이 더 중요하다고 생각합니다.
